# ☕ Introdução à Programação Orientada a Objetos em Java

Este repositório foi criado para armazenar meus estudos e práticas do curso **Introdução à Programação e Programação Orientada a Objetos (POO) em Java**, realizado pela plataforma **DIO (Digital Innovation One)**.

O objetivo é consolidar os principais conceitos da linguagem Java e da POO por meio de exemplos práticos, exercícios e pequenos projetos.

---

## 📚 Conteúdos estudados

Durante o curso, estou aprendendo e praticando os seguintes tópicos:

- Fundamentos da linguagem Java  
- Estrutura de classes e objetos  
- Atributos e métodos  
- Construtores  
- Encapsulamento  
- Herança  
- Polimorfismo  
- Abstração  
- Modificadores de acesso (`public`, `private`, `protected`)  
- Pacotes e organização de código  
- Boas práticas de POO  

---

## 🧠 Objetivo do repositório

Este repositório tem como finalidade:

- Fixar os conceitos de Java e POO  
- Servir como material de consulta futura  
- Mostrar minha evolução no aprendizado da linguagem  
- Construir uma base sólida para projetos mais avançados  

---

## 🛠️ Tecnologias utilizadas

- **Java**
- **VS Code / IntelliJ IDEA**
- **JDK**
- **Git & GitHub**
- **Plataforma DIO**
